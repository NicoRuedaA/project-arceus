## Auxiliary Data CodeUnit method variance

The earlier range reconciliation classified all 7,637,508 gap bytes across the four auxiliary modules as Instruction or **defined Data** and zero Undefined bytes (`p0-auxiliary-range-reconciliation.md:48-62,83-86`). The later read-only scan tested `Data.isDefined()` on intersecting **CodeUnits** and found predominantly Undefined-type Data units: `rtld` 0 defined / 856 undefined-type; `sdk` 5 / 3,970,300; `subsdk0` 9 / 1,084,159; `subsdk1` 10 / 104,832 (`p0-auxiliary-gap-reference-triage.md:37-52`). These are different measurement units and classification methods; the reports themselves identify a method discrepancy, not a changed body union (`p0-auxiliary-gap-reference-triage.md:95-113`). Preserve **both** recorded outcomes and the disagreement. Do not infer functions, code validity, semantic data, or reachability from either classification or the gap CALL/JUMP candidates (`p0-auxiliary-gap-reference-triage.md:74-93`). Method reconciliation is Deferred beyond the bounded P0 inventory baseline.
