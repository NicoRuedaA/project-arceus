**Result:** The reviewed static function evidence is suitable for a bounded base-v0 + update-v262144 inventory/provenance baseline, provided the Wave B canonical records retain every Unknown below and Wave C confirms the current fingerprints and gates. It is **not** a complete valid-function inventory, semantic analysis, runtime observation, or port-progress claim. Base v0 `main` is provenance-only; the update is a patch applied to the mandatory base game.

This was a read-only review of sanitized reports and permitted inventory hashes. No package manifest JSON, sensitive configuration, payload, Ghidra process, `gamedb index`, or treemap generator was read or run. The generated fix2 status and Rust fingerprint are **reported** by the sanitized profile; they are not independently verified here because this Wave A review did not read a JSON manifest or traverse Rust sources.

## Index and method boundaries

- The completed index covers exactly the **available six-root C corpus**, not all functions or all game content: **177,795 files, 176,667 parsed function rows, 1,128 files without a parsed row**, with **87/87 selftests**. Per-role values in the matrix are from the final successful retry. A no-row C file is a parser/index result, not evidence that its source or original body is empty. [Global index, lines 131–174](p0-global-gamedb-index.md). The six source/staged roots had a recorded 177,795/177,795 byte-for-byte pairing; [source verification, lines 9–24 and 56–68](p0-global-gamedb-source-verification.md). No new indexing is justified by this review.
- The global index report now opens with the successful current status and labels the earlier empty database as historical: [global index, lines 3–10](p0-global-gamedb-index.md). The older [static gate report, lines 120–160](p0-final-static-inventory-gate.md) still carries its then-correct **FAIL** verdict for that formerly stale opening; it is a dated finding, not evidence that the corrected opening is still stale.
- The old update-only index value of **153,470 parsed rows** is not the current global index's **152,634**. Likewise the legacy capped update profile (68,330 entries) is not fix2's 153,476-entry baseline. Preserve snapshot/version identity rather than mixing numerators. [Function-scope matrix, lines 69–85](p0-function-scope-matrix.md); [fix2 profile, lines 3–28](p0-fix2-treemap-profile.md).
- The auxiliary range snapshot has **27,349** detections versus the export run's **27,750**: a **401-detection run/configuration difference**, not a discovered 401 missing valid functions. Of 20,327 exports, **19,973 IDs** match the range snapshots; **354** do not (162 `sdk`, 89 `subsdk0`, 103 `subsdk1`). Cause and exact body-size reconciliation remain **Unknown**. [Auxiliary range reconciliation, lines 50–89](p0-auxiliary-range-reconciliation.md); [auxiliary export inventory, lines 75–80](p0-auxiliary-module-export-inventory.md).
- Preserve both incompatible auxiliary listing classifications. The range report labels gap bytes as **2,477,224 instruction / 5,160,284 defined Data / 0 undefined** in total; the later `Data.isDefined()` pass classifies most gap Data CodeUnits as **Undefined-type Data**, without changing the body/gap boundaries. [Range reconciliation, lines 50–60 and 83–89](p0-auxiliary-range-reconciliation.md); [gap/reference triage, lines 37–52 and 95–116](p0-auxiliary-gap-reference-triage.md).
