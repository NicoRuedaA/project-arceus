## Verified / Assumed / Unknown

- **Verified by this measurement**: per-area load/chunk/navmesh/albedo wall-clock times, content counts, decoded mesh bytes, process RSS; the offscreen loop's CPU frame times are measured values of this scene on this machine.
- **Assumed**: the offscreen scene (one camera pose per area, radius-limited trees) is representative of the viewer's views; `RSS Δ` attribution ignores allocator reuse; the 60-fps budget below is a proposal, not a decoder fact.
- **Unknown**: GPU frame time of the windowed viewer; GPU memory; frame times with the player moving / streaming continuously (this run is static); behaviour on other hardware; whether the maintainer's improved terrain textures are active (`play.sh` overlays `work/texturas_mejoradas`, this run uses the plain cache).

## Proposed budget (ASSUMED)

60 fps = 16.6 ms per frame is proposed as the target until the maintainer defines one.
The offscreen CPU loop above stays under that figure only for the scenes measured here;
without GPU numbers this is not a verdict on the viewer's frame rate.
